### What I'm actually working on

- **Self-hosted everything.** A two-node Proxmox lab across five VLANs — media pipeline,
  shared Postgres, centralized logging, reverse proxy, DNS. The `*arr` tools above are the
  parts that turned out to be worth packaging for other people.
- **Autonomous workflows.** I run a custom harness for AI agents on my own hardware. It
  stays private, but it's where most of my time goes — and it has a hand in a lot of what
  you see here.
- **The engineering side.** Some of this points back at the day job, where the tolerance
  for software that almost works is a lot lower. That work lives on its own.

### Stack

`Python` · `FastAPI` · `PostgreSQL` · `Docker` · `htmx` · `Jinja2` · `FFmpeg` · `Proxmox` · `nginx`

No frameworks I can't debug at 2am. Server-rendered, boring on purpose, runs unattended.
